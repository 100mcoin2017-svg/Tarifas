# Tarifas Margarita

App web de una sola página con la lista de tarifas de transporte por destino en
Isla Margarita (playas, hoteles y destinos).

## Características

- Buscador de destinos, playas y hoteles (sin acentos, tolerante a errores).
- Tarifa de **día** y **noche** (cambia sola según la hora; 6:00 pm a 5:59 am = noche).
- Conversión a bolívares con la **tasa BCV**, que se actualiza sola una vez al día
  (vía `ve.dolarapi.com`) y puede escribirse a mano.
- **Favoritos** (★) y orden A–Z o por precio.
- Toca un destino para copiar la tarifa al portapapeles.
- Funciona **sin internet** (datos y preferencias guardados en el navegador).

## Uso

Abre `index.html` en cualquier navegador. No requiere servidor ni dependencias.
